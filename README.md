# NeuroLearn
An interactive neuro-oncology learning platform combining image-based tumour classification with educational content to support revision of common brain tumours.

#Overview
NeuroLearn is an interactive educational project developed to support learning and revision of common brain tumour types. The application combines image-based tumour classification with active recall and evidence-based explanations to help students strengthen their understanding of neuro-oncology.
The project was created to demonstrate how computational tools can be used to enhance biomedical education while providing practical experience in Python programming, scientific communication and user-centred educational design.


Objectives:
- Reinforce knowledge of common brain tumour types.
- Encourage active recall through interactive quizzes.
- Improve confidence in recognising imaging features.
- Demonstrate the use of Python for biomedical education.
- Explore the intersection of computational biology and medical education.

Why I Built This
This project was inspired by my interest in neuro-oncology and translational biomedical research. During my Biomedical Sciences degree, I became increasingly interested in how computational tools can support both scientific research and medical education.

Rather than creating a traditional revision resource, I wanted to develop an interactive platform that encourages active learning while reinforcing key concepts in neuro-oncology.

NeuroLearn was created as both an educational resource and a personal learning project to strengthen my understanding of neuro-oncology while developing computational skills. Before exploring machine learning approaches to brain tumour classification, I wanted to build a strong foundation in the underlying tumour biology and create a revision tool that encouraged active learning through image recognition and evidence-based explanations.

The long-term aim of this project is to expand NeuroLearn by incorporating machine learning techniques to investigate computational approaches to brain tumour classification, bridging biomedical education with applied data science.

This project reflects my interest in combining biomedical science, computational methods and education to develop tools that support both learning and future translational research.
